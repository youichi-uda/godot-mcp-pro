# Godot MCP Pro

Премиальный MCP (Model Context Protocol) сервер для разработки игр на Godot с помощью ИИ. Подключает ИИ-ассистентов, таких как Claude, напрямую к вашему редактору Godot с **187 мощными инструментами**.

## Архитектура

```
AI Assistant ←—stdio/MCP—→ Node.js Server ←—WebSocket:6505—→ Godot Editor Plugin
```

- **Реальное время**: соединение через WebSocket дает мгновенную обратную связь без опроса файлов
- **Интеграция с редактором**: полный доступ к API редактора Godot, системе UndoRedo и дереву сцены
- **JSON-RPC 2.0**: стандартный протокол с корректными кодами ошибок и подсказками

## Что находится в этом репозитории

> ⚠️ **Этот публичный репозиторий содержит только бесплатный аддон/плагин для Godot.** MCP-сервер (Node.js, необходим для подключения ИИ-ассистентов) распространяется в составе платного пакета — **разовая покупка**, пожизненные обновления:
>
> - **Buy Me a Coffee**: <https://buymeacoffee.com/y1uda/extras>
> - **itch.io**: <https://y1uda.itch.io/godot-mcp-pro>
>
> Платный zip-архив включает аддон, каталог `server/` с заранее собранным JavaScript, `INSTALL.md` и инструкции для ИИ-клиентов. Если вы клонировали этот репозиторий и не видите папку `server/`, **так и должно быть** — скачайте полный пакет по одной из ссылок выше.

## Быстрый старт

### 1. Установка плагина Godot

Скопируйте папку `addons/godot_mcp/` в каталог `addons/` вашего проекта Godot.

Включите плагин: **Project → Project Settings → Plugins → Godot MCP Pro → Enable**

### 2. Установка MCP-сервера

> Каталог `server/` входит только в **полный платный пакет** (см. выше). После загрузки и распаковки zip-архива выполните:

```bash
cd server
npm install
npm run build
```

### 3. Настройка Claude Code

Добавьте в ваш `.mcp.json`:

```json
{
  "mcpServers": {
    "godot-mcp-pro": {
      "command": "node",
      "args": ["/path/to/server/build/index.js"],
      "env": {
        "GODOT_MCP_PORT": "6505"
      }
    }
  }
}
```

### 4. Выбор режима

Godot MCP Pro предлагает четыре режима, чтобы уложиться в лимит инструментов любого клиента:

| Режим | Инструменты | Лучше всего для |
|------|-------|----------|
| **Full** (по умолчанию) | 187 | Claude Code, Cline, VS Code Copilot, Cursor |
| **3D** (`--3d`) | 100 | Antigravity и другие клиенты с лимитом 100 инструментов, которым нужен 3D |
| **Lite** (`--lite`) | 88 | Windsurf, JetBrains Junie, Gemini CLI |
| **Minimal** (`--minimal`) | 35 | OpenCode, локальные LLM с небольшим контекстом |

`--3d` включает основные инструменты, а также физику, AnimationTree и навигацию, но исключает `uid_to_project_path`, `project_path_to_uid`, `compare_screenshots`, `clear_output`, `close_script`, `reload_open_scripts`, `set_anchor_preset` и `click_button_by_text`, чтобы уложиться в лимит 100 инструментов.

```json
{
  "mcpServers": {
    "godot-mcp-pro": {
      "command": "node",
      "args": ["/path/to/server/build/index.js", "--lite"]
    }
  }
}
```

Замените `--lite` на `--minimal` для минимального объема.

- **Lite** включает: инструменты project, scene, node, script, editor, input, runtime и input_map.
- **Minimal** включает: 35 основных инструментов — информация о проекте, управление сценами, CRUD узлов, редактирование скриптов, ошибки редактора, симуляция ввода и инспекция во время выполнения.

### 5. Режим CLI (альтернатива MCP)

Для клиентов без поддержки MCP или когда нужны нулевые накладные расходы на контекст, используйте CLI напрямую из терминала/bash-инструмента. Для CLI сервер должен быть предварительно собран (шаг 2).

```bash
# Top-level help — shows all command groups
node /path/to/server/build/cli.js --help

# Group help — shows commands in a group
node /path/to/server/build/cli.js node --help

# Command help — shows options for a command
node /path/to/server/build/cli.js node add --help

# Execute
node /path/to/server/build/cli.js project info
node /path/to/server/build/cli.js scene play
node /path/to/server/build/cli.js node add --type CharacterBody3D --name Player
```

Замените `/path/to/` на фактический путь, куда вы распаковали файлы.

CLI подключается напрямую к плагину редактора Godot через WebSocket. Требования:
- Запущенный редактор Godot с включенным плагином MCP
- Собранный сервер (`node build/setup.js install`)
- Свободный порт в диапазоне 6510-6514

**Преимущество**: LLM узнают о возможностях постепенно через `--help`, а не загружают все определения инструментов заранее. Это работает с любым LLM-клиентом, имеющим доступ к терминалу, независимо от лимитов на количество инструментов.

### 6. Совместимость клиентов

| Клиент | Рекомендуемый режим | Примечания |
|--------|-----------------|-------|
| Claude Code | Full (по умолчанию) | Отложенная загрузка инструментов — минимальные затраты контекста |
| VS Code Copilot | Full | Virtual Tools автоматически группируют инструменты |
| OpenAI Codex CLI | Full | MCPSearch откладывает избыточные инструменты |
| Cline | Full | Нет жесткого лимита; используйте `enabledTools` для белого списка |
| Roo Code | Full | Нет жесткого лимита |
| Windsurf | Lite | Лимит 100 инструментов |
| JetBrains Junie | Lite | Лимит 100 инструментов |
| Gemini CLI | Lite | Лимит клиента ~100; используйте `excludeTools` для точной настройки |
| Cursor | Full | Лимит инструментов снят (Dynamic Context Discovery) |
| OpenCode | Minimal или CLI | Модели деградируют после ~40 инструментов |
| Локальные LLM (LM Studio и др.) | Minimal или CLI | Узкое место — окно контекста |

### 7. Использование

Откройте ваш проект Godot с включенным плагином, затем используйте Claude Code для взаимодействия с редактором.

## Ключевые возможности

- **Интеграция с UndoRedo**: все операции с узлами/свойствами поддерживают Ctrl+Z
- **Умный разбор типов**: `"Vector2(100, 200)"`, `"#ff0000"`, `"Color(1,0,0)"` преобразуются автоматически
- **Автопереподключение**: переподключение с экспоненциальной задержкой (1s → 2s → 4s ... → 60s max)
- **Heartbeat**: ping/pong каждые 10s поддерживает соединение
- **Полезные ошибки**: ответы с ошибками содержат подсказки для следующих шагов
